# المرحلة 5: الغرفة السريعة

تختصر هذه المرحلة إنشاء غرفة مستطيلة إلى خطوتين: اختر ركنين، فينشئ CivilDraft أربعة جدران ومنطقة باسم اختياري داخل معاملة واحدة.

- `quickroom` أو `qroom` أو `غرفة_سريعة`.
- التراجع مرة واحدة يحذف الجدران والمنطقة معاً.
- الشكل الصفري أو الفشل لا يترك حالة جزئية.
- المساحة والاسم يبقيان في نموذج CivilDraft الحالي، ولا يوجد مخزن غرف ثانٍ.
