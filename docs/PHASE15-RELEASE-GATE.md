# المرحلة 15: بوابة الإصدار الأول

## الاختبارات الآلية

```bash
npm test
npm run check
npm run build
```

## اختبار المتصفح

1. شغّل `npm run serve` وافتح `http://localhost:8080`.
2. افتح `guidedroom` من لوحة الأوامر.
3. أنشئ غرفة بمقاس `٥م × ٤م`.
4. اكتب الاسم `مجلس`.
5. أضف باباً عند `٢٫٥م` بعرض `٩٠٠ ملم`.
6. افحص المعاينة 2D و3D.
7. التزم، ثم نفّذ `Ctrl+Z` مرة واحدة.
8. تأكد أن الجدران والمنطقة والباب اختفوا معاً.
9. أعد الفتح من ملف محفوظ، وتأكد من بقاء الجدران والفتحة والاسم.
10. اختبر الأدوات القديمة: `wall`, `rect`, `open`, `3d`, `dxf`.

## قرار الإصدار

لا تُوسم النسخة إلا بعد نجاح الاختبارات الآلية واختبار المتصفح وعدم وجود أخطاء في وحدة التحكم. هذه البوابة توثق معيار القبول، ولا تدّعي تشغيل الاختبارات من GitHub API.
