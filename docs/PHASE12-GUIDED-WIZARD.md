# المرحلة 12: معالج الغرفة المرئي

أضيفت نواة المعالج المحضة `core/guided-room-wizard.js` وواجهة DOM المعزولة `ui/guidedroom.js`، ثم جسر الالتزام `ui/guidedroom-action.js` الذي يمرر المعاينة إلى `commitGuidedRoom` داخل معاملة واحدة.

التدفق: **المقاس → الاسم → الباب → المعاينة → الالتزام**. الإلغاء لا يلمس `S`، والفشل يظهر كتقرير ولا يترك غرفة نصف مكتملة.

بقي تركيب زر أو أمر CivilDraft نفسه واختبار المتصفح النهائي. لا تُستدعَ الواجهة تلقائياً من شاشة الإقلاع لأنها تحتاج حدثاً صريحاً من المستخدم.
