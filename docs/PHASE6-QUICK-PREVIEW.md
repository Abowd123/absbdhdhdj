# المرحلة 6: المعاينة قبل الالتزام

أضيفت دوال محضة لمعاينة الجدار والغرفة قبل تعديل الحالة. المعاينة لا تنشئ كيانات ولا تدخل التاريخ؛ الالتزام وحده يمر عبر المعاملة الذرية.

بوابة القبول: حرّك المؤشر بعد نقطة البداية، تحقق من ظهور الطول والزاوية، ثم انقر للالتزام. اضغط Esc قبل الالتزام وتأكد أن الحالة لم تتغير.
